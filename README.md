# Zipmod Utility

Zipmod Utility is a tool designed to make managing, identifying, and organizing your Koikatsu mod collection easier. Whether you're trying to identify incorrectly named mods, track down missing dependencies for a character card, or clean up duplicate files, Zipmod Utility provides a straightforward way to handle it all.

## Features

- **Zipmod Identification:** Scan individual `.zipmod` files or entire folders in bulk to identify their actual mod names using the information contained within each file. Names are identified in the same format displayed by Koikatsu when a character card is missing a required mod.

- **Bulk Renaming:** Rename individual or multiple `.zipmod` files to their actual identified names, making it easier to keep your mod collection properly labeled and organized.

- **Card Dependency Scanner:** Scan character cards to see which mods they require and which ones you already have installed. Missing mods are clearly identified, with the ability to right-click and copy a missing mod's GUID, making it easier to search for and track down the files online.

- **Duplicate Mod Detection:** Scan your mod collection for duplicate `.zipmod` files, even when they have different filenames. Duplicates are identified by comparing the GUIDs contained within the files, allowing you to easily locate and separate redundant mods.

- **Drag & Drop Support:** Easily load `.zipmod` files and character cards by dragging and dropping them directly into the application.

## Simplify Your Mod Management

Spend less time sorting through incorrectly named files, tracking down missing dependencies, and hunting for duplicates. Zipmod Utility brings several useful mod-management functions together in one convenient place.
